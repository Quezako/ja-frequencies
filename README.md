# Japanese Frequency Lists – Learning Priority Project

This project aims to organize and prioritize Japanese vocabulary using several frequency sources, in order to produce more useful word lists for learning, especially within an Anki workflow.

The main goal is to combine:
- general frequency lists;
- spoken / conversational vocabulary sources;
- fiction and media corpora;
- JLPT and pedagogical data;
- kanji statistics.

The result is a prioritization system that ranks words according to their importance for communication, reading, immersion, and progressive learning.

---

## Project goal

The repository allows you to:

- analyze frequency files and data sources;
- compare multiple lists and classify words by importance;
- generate learning priorities (`priority_general`, `priority_oral`, `priority_professional`, `priority_fiction`, `priority_kanji`);
- enrich vocabulary lists from an Anki deck or local export;
- prepare exports that can be re-imported into Anki.

## Main scripts

### `analyze_frequency_files.py`

This script scans an external data folder and produces a summary report covering:
- files present;
- file size;
- file header;
- number of lines;
- possible exact or near-duplicate files.

It is mainly used to inventory frequency sources and validate their consistency before deeper processing.

Example usage:

```bash
python analyze_frequency_files.py
```

### `build_priority_orders.py`

This script loads frequency lists from `20-data/` and assigns priority scores to each entry across several dimensions:

- `priority_general`: overall importance of the word;
- `priority_oral`: spoken / conversational vocabulary;
- `priority_professional`: formal / professional vocabulary;
- `priority_fiction`: fiction and immersion vocabulary;
- `priority_kanji`: importance of the kanji present in the word.

The script looks up words in the reference sources, applies ranking rules, and generates output files in `10-output/`.

Example usage:

```bash
python build_priority_orders.py
```

### 4. Kanji data
- kanji frequency data;
- relationships between reading, frequency, and character learning.

## Recommended workflow

1. Check the files in `00-input/`.
2. Analyze the sources with `analyze_frequency_files.py`.
3. Validate the links between the data and the frequency lists.
4. Run `build_priority_orders.py` to generate the priority rankings.
5. Review the results in `10-output/`.
6. Re-import the result into Anki or another memorization tool.

---

## Best practices

- Keep files in their dedicated folders (`00-input`, `10-output`, `20-data`).
- Do not modify raw source data directly without keeping a backup.
- Check duplicates and file variants before treating a list as the source of truth.
- Work with explicit frequency, rank, and priority columns to avoid merge errors.

---

## Key idea

This project is not just a list of words by frequency; it is a pedagogical filtering method for Japanese vocabulary, designed to move from the most useful to the rarest items while integrating language register, media context, and progressive learning needs.
